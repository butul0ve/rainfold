Стандартная команда полного прогона остановилась на HTTP 429 Maven Central при загрузке существующей зависимости `org.robolectric:nativeruntime-dist-compat:1.0.18`. Оба штатных Maven Central hostname отвечают 429. Отдельная диагностическая попытка Robolectric без этого native-архива также остановилась до тестового метода: отсутствующий Android sandbox не загружается с Maven. Это сетевой блокирующий фактор, а не результаты Android-тестов.

Для независимых от Android domain/DSP/fake-output тестов, сборки и lint использован временный `/tmp/rainfold-no-native.init.gradle`:

```groovy
allprojects {
    configurations.configureEach {
        exclude group: 'org.robolectric', module: 'nativeruntime-dist-compat'
    }
}
```

Исключение только тестовой runtime-зависимости задано запуску, не проекту/CI/дистрибутиву APK. Точная команда:

```bash
source /workspace/.rainfold-env/env.sh
./gradlew :app:testDebugUnitTest \
  --tests 'com.rainfold.app.domain.*' --tests 'com.rainfold.app.dsp.*' \
  --tests 'com.rainfold.app.player.NoisePlayerTest' :app:assembleDebug :app:lintDebug --offline \
  -I /tmp/rainfold-tests.init.gradle -I /tmp/rainfold-no-native.init.gradle \
  -Pkotlin.compiler.execution.strategy=in-process \
  '-Dorg.gradle.jvmargs=-Xmx1536m -XX:MaxMetaspaceSize=768m -Dfile.encoding=UTF-8'
```

Все новые Robolectric-тесты компилируются, но сервисные/notification сценарии этой итерации ещё не выполнялись из-за недоступного sandbox. После восстановления Maven запустить обычный полный `:app:testDebugUnitTest :app:assembleDebug :app:lintDebug` без исключения и без фильтров. Затем отдельно согласовать проверку на устройствах; adb/emulator/install не использовались.

## Что реализовано в этапе 3

- Чистая доменная библиотека `SceneLibrary`: неизменяемые рецепты, стабильные ID, избранное, выбранная сцена, сохранение новой/переименование/удаление. До 100 пользовательских сцен с названиями 1–60 символов. Встроенные рецепты нельзя менять или удалять.
- Пять локализованных пресетов: Deep Sleep (коричневый шум), Rainy Window (дождь с muted-шумом), Quiet Focus (розовый шум + тихий дождь), Cozy Storm (коричневый шум + более громкий дождь) и Airplane Cabin (белый шум). Последние два используют имеющиеся источники без грома/записи самолёта; это указано в интерфейсе.
- Рецепт хранит тип шума, обе громкости, наличие дождя, оба mute и подпись Sleep/Focus. Таймер и fade — отдельные настройки сессии. Подписи не реализуют режимы этапа 4 и не меняют таймер автоматически.
- Сервис владеет библиотекой и обрабатывает команды `SCENE`. Сохранение захватывает его актуальный микс. Выбор сцены обновляет существующий mixer и сохраняет AudioTrack/дедлайн. Выбор в Idle/Paused не включает звук; Play из карточки явно запускает/возобновляет. Копирование не переключает сцену; удаление не меняет текущий звук.
- Версионированный JSON хранится вместе с текущим миксом в приватных SharedPreferences. Старые установки сохраняют микс без автоматического выбора пресета. Повреждённый рецепт пропускается независимо от остальных; потерянные ссылки selected/favorite убираются.
- Последний выбранный рецепт и несохранённые правки восстанавливаются в Idle. Изменённый рецепт отмечен в заголовке, исходник не перезаписывается автоматически. Название сцены показывается в системных медиаконтролах.
- Новый главный экран: название/контекст/статус/таймер, слои, библиотека сцен, добавление звука, таймерный sheet, сохранение. Play/Pause закреплена и доступна в sheet. Список сцен ленивый, чтобы не создавать сразу 100 карточек. Диалоги имени и удаления, избранное, EN/RU, описания шумов и пресетов.
- Статичный градиент по контексту, приглушение фона во время Sleep-воспроизведения, сохраняемый AMOLED-вариант. Движущегося фона нет. Appearance хранится ViewModel отдельно от аудиосервиса.
- JSON пересчитывается только при изменении библиотеки, а ViewModel разбирает его только при изменении строки; тики таймера не сериализуют и не разбирают все рецепты заново.

Версия, зависимости APK, разрешения, DSP, исходный дождь и аудиорендерер не менялись. Полная автономность сохранена.

- Сервис владеет AudioTrack/focus/wake lock/foreground; удаление recent-task останавливает сессию. Android Bundle получает только присутствующие поля, не обнуляя соседние настройки.
